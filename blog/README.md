# 내 블로그 (GitHub Pages)

## 배포 방법
1. GitHub에서 새 저장소를 만듭니다. 이름은 반드시 `아이디.github.io` (Public)
2. 이 폴더의 파일 전체를 저장소 루트에 올립니다 (Add file → Upload files)
3. 1~2분 뒤 https://아이디.github.io 로 접속

## 내 정보 바꾸기
`posts.js` 맨 위 `SITE`의 TODO 항목(이름, GitHub 아이디, 이메일, 태그)을 수정하세요.
`about.html`의 소개글과 활동/경력도 본인 내용으로 바꿔 주세요.

## 새 글 쓰기
1. `posts/hello.html`을 복사해 새 파일로 저장하고 내용을 수정
2. `posts.js`의 `POSTS`에 한 줄 추가 (category: dev / ctf / bugbounty / docs / papers / contests)
