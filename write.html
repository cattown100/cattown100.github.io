3. 사진 · 파일 첨부

      GitHub 웹 업로드는 파일 하나당 25MB까지예요. 큰 파일은 따로 올리고 링크로 거세요.

      4. 등록

      토큰은 내 브라우저에서 GitHub로만 전송돼요. 남의 컴퓨터에서는 기억하기를 끄세요. 토큰 만드는 방법

      1. GitHub 오른쪽 위 프로필 → Settings → Developer settings
      2. Personal access tokens → Fine-grained tokens → Generate new token
      3. Repository access는 Only select repositories로 이 블로그 저장소 하나만 선택
      4. Permissions → Repository permissions → Contents: Read and write
      5. 만료일(예: 90일)을 정하고 만들기 → 나온 github_pat_… 값을 위 칸에 붙여넣기

      직접 올리기 (zip으로 받아서 GitHub에 업로드)
      1. zip을 풀면 posts/, images/, files/ 폴더가 나와요.
      2. GitHub 저장소 → Add file → Upload files에 그대로 끌어다 놓고 Commit.
