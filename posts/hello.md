## 이 블로그에 대해

학습 과정과 활동 기록을 꾸준히 남기려고 만들었어요. 보안과 개발을 공부하며 푼 문제, 읽은 논문, 도전한 공모전까지 **카테고리별로** 정리합니다.

> 기록하지 않은 공부는 금방 사라진다. 짧게라도 남기자.

## 글에 쓸 수 있는 것들

### 코드

언어를 지정하면 색이 입혀지고, 오른쪽 위 버튼으로 바로 복사할 수 있어요.

```python
def solve(flag: str) -> bool:
    # CTF 라이트업에서 자주 쓰는 형태
    return flag.startswith("FLAG{") and flag.endswith("}")

print(solve("FLAG{hello_pages}"))
```

## 새 글 올리는 법

1. `posts/슬러그.md` 파일을 만들어 본문을 마크다운으로 써요. 사진은 `images/슬러그/`, 첨부 파일은 `files/슬러그/`에 넣어요.
2. `posts.js`의 `const POSTS = [` 바로 아래에 글 정보(제목, 날짜, 카테고리 등) 덩어리를 추가해요.
3. 변경 내용을 커밋하고 푸시해요. (`git add .` → `git commit -m "새 글: 제목"` → `git push`)

1~2분 뒤 사이트에 새 글이 나타나요.
